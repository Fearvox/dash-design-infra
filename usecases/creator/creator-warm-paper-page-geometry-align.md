# Warm-Paper Page Geometry Alignment

This is the second slice in the warm-paper page-geometry axis. The first
slice (PR #152) shipped a diagnostic phenotype that documented 3
role-distinguished padding patterns across the 6 warm-paper surfaces and
identified the only fully addressable drift: a 4px and 2px drift on
Pattern A's outer page padding. This slice implements the smallest
concrete alignment that closes that drift.

## What it solves

Warm-paper surfaces use 3 distinct page-geometry patterns:

- **Pattern A** &mdash; page is the visible card, padding is the
  outer card inset. Used by: family-dna, motion-storyboard,
  poster-surface, prompt-dna-adapter.
- **Pattern B** &mdash; page is a transparent canvas with a content
  shell inside. Used by: motion-storyboard, prompt-dna-adapter,
  social-card.
- **Pattern C** &mdash; page is a frame with a `::before` decorative
  inset. Used by: pdf-zine, social-card.

Pattern A surfaces had a real drift: motion-storyboard at 52px,
poster-surface at 58px, prompt-dna-adapter at 56px. family-dna's
asymmetric 44&times;52&times;32 is a family signature (title-then-card
rhythm) and is preserved.

## What it produces

A 2-edit surface mutation:

- `creator-motion-storyboard.html` &mdash; `.page { padding: 56px }`
  (was 52px)
- `creator-poster-surface.html` &mdash; `.page { padding: 56px }`
  (was 58px)

Both align to the prompt-dna-adapter anchor, the largest Pattern A
surface in the warm-paper family. family-dna's asymmetric
44&times;52&times;32 is preserved as family signature.

No token layer is introduced. This is a pure value alignment, not a
grammar extension. If a future slice introduces `--pad-page`, the
token value would simply be `56px` and the surface edits would already
be in place.

## Layer model

```text
1. warm-paper .page padding (the focus of this slice)
2. warm-paper .shell padding (Pattern B inner container &mdash;
   paired 4px drift: motion-storyboard 40px vs prompt-dna 44px)
3. .page::before inset (Pattern C frame &mdash; pdf-zine 56px,
   social-card 44px 80px)
```

This slice addresses layer 1 only. Layer 2 and layer 3 are confirmed
family signature per the diagnostic &mdash; Pattern B has rhythm
variation that is intentional, Pattern C has only 2 surfaces with
distinct canvas sizes (1684x1191 vs 1200x630) so the inset values
serve different visual roles.

## Commands

```bash
# Verify the surface edits
bun measure:check -- examples/creator-motion-storyboard.html
bun measure:check -- examples/creator-poster-surface.html
bun print:render -- examples/creator-motion-storyboard.html /tmp/ms.pdf --canvas=1684x1191
bun print:render -- examples/creator-poster-surface.html /tmp/ps.pdf --canvas=1684x1191

# Convergence check
bun creator:surface-consistency
bun creator:cache-integrity
bun creator:multi-surface-proof
```

## QA checks

- `bun measure:check` PASS for both edited surfaces
- `bun print:render` PASS for both edited surfaces (1 page each, fixed
  1684x1191 canvas)
- `bun creator:surface-consistency` reports Pattern A drift reduced
  from 3 distinct values to 1 (the new anchor)
- `bun creator:cache-integrity` reports 11/11 valid (or 13/13 with
  diagnostic, no stale entries)
- `bun creator:multi-surface-proof` reports measure+print PASS for
  both edited surfaces
- `bun hackathon:score` MAXXED

## Failure modes

- **Visual layout collision** &mdash; if motion-storyboard's 6-row grid
  (`66px minmax(0,1fr) 38px`) was hard-tuned to 52px padding, the +4px
  alignment could push content to overflow. measure:check catches
  this; if it fires, reduce the gap:22px in `.shell` to gap:18px to
  recover.
- **Poster card overflow** &mdash; poster-surface has a 1040px max-width
  inner content area. -2px on padding is well within safe margin; no
  expected impact.
- **Family-dna accidental drift** &mdash; if a future slice aligns
  family-dna's 44&times;52&times;32 to 56px symmetric, it will lose
  the title-then-card rhythm. This slice deliberately does not touch
  family-dna.

## Public boundary

This slice edits only 2 public creator surface HTML files. No
generated media, no internal paths, no secrets, no operator
material. The convergence JSON is auto-regenerated by
`bun creator:surface-consistency` and contains only public-safe token
audit data.
