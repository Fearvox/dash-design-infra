F1 Page geometry pattern inventory

Six warm-paper surfaces were audited for how they distribute padding between the fixed 1684×1191 canvas and the inner content. Three distinct patterns emerged — not arbitrary drift, but role-distinguished layout strategies:

Surface Outer (page / shell) Inner (shell / sheet / capsule) Pattern
creator-family-dna.html .page padding: 44px 52px 32px — A: direct page padding
creator-poster-surface.html .page padding: 58px .poster padding: 44px A+B: page + poster subframe
creator-motion-storyboard.html .page padding: 52px .shell padding: 40px A+B: page + shell
creator-prompt-dna-adapter.html .page padding: 56px .capsule-shell padding: 44px A+B: page + capsule-shell
creator-social-card.html .shell padding: 44px 54px — A: shell padding (1200×630 canvas)
creator-pdf-zine.html .sheet padding: 70px .page::before inset: 56px (frame) B+C: sheet + dashed frame

Conclusion: page-geometry is not arbitrary drift. The three patterns correspond to three roles: (A) layout canvas = the page itself is the visible card, (B) inner container = the page is a transparent background and the content frame lives inside, (C) frame inset = the page receives a decorative dashed border frame, separate from the content well.

Composite — what the agent should check for

A new warm-paper surface must choose one of the three patterns and stick to it. The decision tree:

  1. Is the page itself the visible card? → Pattern A (page padding 44–58px).
  2. Is the page a transparent canvas with a content card inside? → Pattern B (page padding 52–58px, inner padding 40–44px).
  3. Does the page need a decorative frame + content well? → Pattern C (frame inset 56px, sheet padding 70px).

Mixed patterns (e.g. poster-surface uses A and B together) are allowed when the surface has a subframe inside a padded page — the subframe is a 2nd-level container, not a separate pattern.

F3 Closest-pair analysis (the only plausible drift)

Within Pattern A, the closest pair is motion-storyboard (52px) and prompt-dna-adapter (56px) — a 4px delta. family-dna uses 52px horizontal but asymmetric vertical (44px 32px) for the “title-then-card” rhythm. poster-surface at 58px is 2px above motion-storyboard. social-card at 44×54 lives on a different canvas (1200×630) and uses asymmetric 44×54.

This is addressable but is a design call (motion-storyboard already has 6 internal grid-template-rows: 66px minmax(0,1fr) 38px sized to 52px, so the inner layout would need recalibration).

F4 Token layer opportunity (design-decision-blocked)

Based on F1-F3, three token candidates could be proposed:

  1. --pad-page: 56px — align page padding across all Pattern A surfaces. Visual delta: motion-storyboard +4px, poster-surface −2px. Closes 1–2 px drift pairs.
  2. --pad-shell: 44px — align inner container padding across all Pattern B surfaces. Visual delta: motion-storyboard −4px, poster-surface 0, prompt-dna 0. Closes inner drift.
  3. --pad-frame: 56px — align frame inset for any future Pattern C surface. Currently only pdf-zine uses this. No addressable drift — only 1 surface uses it.

Decision blocker: introducing --pad-page / --pad-shell requires a creator/design verdict on whether the 44–58px range is the warm-paper family’s “page padding rhythm” (intentional spread) or arbitrary drift (should be uniform). The visible difference between 52px and 56px is < 1% of canvas width on a 1684px-wide page — the visual change is real but subtle.

Recommendation: hold the token proposal until the creator issues a design call. The current state is a valid family signature (rhythm via subtle variation) just as much as a candidate for unification.

F6 Hardcoded spacing inventory (per-surface grammar)

The convergence file (examples/creator-surface-convergence.json » spacing_audit) already exposes every warm-paper surface’s hardcoded gap / padding / margin values. This finding cross-references those values with the three page-geometry patterns above to document the family’s spacing grammar in concrete numbers. Family DNA = small value vocabulary (2–6 distinct values per surface), not a token layer.

Grammar observation: each warm-paper surface uses between 6 and 11 distinct spacing values total. No surface uses more than 5 distinct gap values or more than 6 distinct padding values. This is the warm-paper family DNA — a compact spacing vocabulary where each value earns its place, distinct from large-scale token-strict systems. The three pattern buckets (A / A+B / B+C) all converge on similar small-value profiles — the pattern is in where the values are placed, not in the values themselves.
