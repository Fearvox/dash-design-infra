Finding — --space-4 token adoption gap

5 warm-paper surfaces have --space-4 in :root but zero body CSS usage. 6 surfaces (family-dna, frontier-capsule, and all dark/creative families) lack --space-4 entirely.

  • poster-surface has hardcoded gap: 16px (×2) that should use var(--space-4)
  • family-dna and frontier-capsule missing --space-4 in :root entirely
  • All 5 warm-paper surfaces with --space-4 in :root have no body usage — the token is declared but unused

Finding — No shared spacing token vocabulary

Gap values range from 4px to 64px across 12 surfaces with no --space-* family layer. This is normal for zine-like layout economy — each gap is a deliberate spacing decision, not drift.

  • No unified --space-* token layer exists across surfaces
  • 16px gaps are the clearest alignment opportunity (poster ×2, family-dna ×1, manim ×1, touchdesigner ×1)
  • For warm-paper surfaces with --space-4 in :root but no body usage: body adoption is the actual next step, not adding more --space-* tokens
