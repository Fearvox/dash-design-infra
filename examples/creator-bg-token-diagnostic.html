Family signature vs. drift

Family signature: same token name means different things in different families. --bg means deep near-black monitoring ground in dark-industrial, and off-white paper in creative-hybrid (frontier-capsule). Converging these would destroy creative intent.

Addressable drift: same token name means the same visual purpose across surfaces in the same family, but values have slightly diverged. Warm-paper --paper (#f2eadb consensus) is addressable drift — all 6 warm-paper surfaces use --paper for the same role.
