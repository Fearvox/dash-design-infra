Finding 1 — ui-serif is not a system font

"ui-serif" is a bare token identifier with no CSS definition. It falls through to the Georgia/Cambria fallbacks that follow it. The naming implies a system-level token but it is surface-local shorthand. Affects 7 surfaces: frontier-capsule, manim-scene, motion-storyboard, pdf-zine, poster-surface, prompt-dna-adapter, social-card.

Finding 2 — 4 surfaces use Georgia directly without ui-serif

browser-demo, family-dna, p5-sketch, remotion-scene use "Georgia, Times New Roman, serif" without the ui-serif wrapper. This is functionally equivalent but not token-consistent. family-dna is the visual grammar reference surface and does not use ui-serif — a potential inconsistency in the reference artifact itself.
