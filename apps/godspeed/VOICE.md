# Voice — how godspeed writes

This is the brand voice playbook. Anyone writing for the site — Roger, future hires, occasional guests — should skim this before they write. The point is consistency, not handcuffs. If a line breaks a rule and feels right, keep it.

## The 5 rules

### 1. Lowercase, almost always.

```text
✓ "good morning sunshine, the world says hello"
✗ "Good Morning, Sunshine — The World Says Hello"
```

Exceptions: proper nouns inside a sentence ("Saluda Ave", "Roger", "Columbia, SC"), and the small handful of moments when you want a stylized Unicode serif for emphasis (see rule 5).

### 2. Talk like a person, not a brand.

```text
✓ "come hang out. order the nectar. stay a while."
✗ "We invite you to enjoy our signature beverage in our welcoming space."
```

Direct. Warm. Use "we", "us", "y'all". Address the reader. Make jokes when something's funny.

### 3. Whimsy is allowed. Corporate vocabulary is not.

```text
✓ "mindblowingly delicious, gobsmackingly good & dangerously slurpable"
✓ "magpie gives you wings 😛"
✓ "✨holiday miracle✨"

✗ "robust", "world-class", "elevated", "curated experience", "leveraging"
✗ "we strive to", "best-in-class", "passionate about"
```

If a word would land on a fortune-500 careers page, it doesn't land here.

### 4. "godspeed" can be an adjective.

```text
✓ "we are off for a godspeed weekend"
✓ "we have been home for one godspeed month"
✓ "it's gonna be a godspeed kind of day"
```

This is a brand quirk we've earned. Use it lightly — not every sentence — but it should show up.

### 5. Stylized Unicode serif: sparingly, for moments.

The IG bio uses `𝐬𝐨𝐦𝐞𝐭𝐡𝐢𝐧𝐠 𝐟𝐨𝐫 𝐞𝐯𝐞𝐫𝐲𝐨𝐧𝐞`. That stylization is a brand signature, but it's a *moment*, not a default. Use it at most:

- The site tagline (already wired)
- A journal post headline that wants to feel like a poster
- A drop announcement

```text
✓ "𝐠𝐝𝐬𝐩𝐝 𝐱 𝐩𝐩𝐣𝐳𝐳 𝟑 — coming this saturday"
✗ "𝐭𝐡𝐞 𝐧𝐞𝐰 𝐦𝐞𝐧𝐮 𝐢𝐬 𝐡𝐞𝐫𝐞 𝐟𝐢𝐧𝐚𝐥𝐥𝐲" (overuse — it loses weight)
```

If a paragraph already has Unicode-bold in it, the next paragraph shouldn't.

## Punctuation

- **Em-dashes are fine.** Use them. We are not afraid.
- **Ellipses** for trailing thoughts, sparingly.
- **Exclamation marks** allowed — keep them honest. One per paragraph max.
- **Emoji**: a few per post is plenty. The good ones: 🥹 🌞 😛 🤪 ✨ 💿. Avoid the ones that look like corporate decks (📊 💡 🎯).

## Word swap cheatsheet

| Don't say | Say instead |
|---|---|
| beverage | drink |
| utilize | use |
| guest | y'all / you / friend |
| signature | house |
| crafted | made |
| journey | story |
| premium | good |
| passionate | excited |
| family-owned | locally run / ours |

## Drink language

- The house drink is **"the nectar"**, lowercase, with the article.
- Sweets are **"lil treats"** as a category.
- Seasonal series are **"drops"** ("the next drop", "drop #3").
- Collabs name the partner first: "gdspd x ppjzz" (not "ppjzz x gdspd").

## When in doubt

Write the sentence. Read it out loud. If you sound like a person standing behind the counter, ship it. If you sound like a press release, cut it down by half and try again.
